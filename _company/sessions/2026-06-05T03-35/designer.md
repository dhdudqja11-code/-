## 🚀 프로젝트: Authority Shield - 통합 프로토타입 스토리보드
**목표:** 데이터 입력 $\xrightarrow{\text{6-8초}}$ 시스템적 통제권 확보 과정의 전문성과 권위 극대화.
**사용 기술 근거:** 코다리님의 `authorityService.ts` 기반 (API 연동, Error/Warning/Success 3단계).

### I. 전체 시퀀스 타이밍 및 분위기 (Timeline & Mood)

| 시간 | 단계 (Phase) | 목적/감정 변화 | 핵심 비주얼 요소 |
| :---: | :---: | :---: | :---: |
| **0-1초** | 🔴 **불안 감지 (Input)** | 사용자에게 '현재의 위협'을 인지시킨다. (공포/긴장) | 노이즈, 어두운 배경, 경고 메시지 강조. |
| **1-4초** | 🟠 **분석 및 식별 (Processing)** | 시스템이 데이터를 분석하고 리스크를 정량화하는 과정에 '권위' 부여. (신뢰/집중) | 플로우차트 애니메이션, 데이터 블록 연결(레고). |
| **4-6초** | 🟢 **통제 확보 (Resolution)** | 위협을 해결하고 권한이 봉인되는 클라이맥스. (안도감/완결성) | 황금색 하이라이트, 인장(Seal) 애니메이션, 명료한 결과 제시. |

### II. 상세 인터랙티브 컴포넌트 사양서 (Hi-Fi Specifications)

#### 🔴 Phase 1: 불안 감지 및 리스크 입력 (0~1초)
*   **배경:** 미세하게 떨리는 노이즈 패턴(Glitch Effect, $\text{Frequency} = 2 \text{Hz}$)을 유지합니다 [근거: Self-RAG]. 전체적인 색감은 청회색 계열에 어두운 그림자 처리를 합니다.
*   **헤드라인:** 중앙에 가장 크게 배치됩니다 (예: "당신의 비즈니스, 혹시 다음 규제 변화에 취약하지 않으신가요?").
*   **인터랙션:** 사용자에게 '걱정되는 법적 리스크 카테고리'를 입력받는 필드가 가장 먼저 포커스 됩니다. 이 필드는 단순 박스가 아닌, **규제 문서의 챕터 제목처럼 보이는 디자인**을 적용합니다 [근거: Self-RAG].

#### 🟠 Phase 2: 시스템 분석 및 위협 식별 (1~4초)
*(클릭 발생 $\rightarrow$ 로딩 스피너 대신 애니메이션 시작)*
*   **시스템 시각화:** 화면이 어두워지며, 코다리님이 구현한 API 호출 플로우(`POST /api/v1/check_authority`)가 중앙에 **단계별 블록 다이어그램**으로 펼쳐집니다 [근거: Self-RAG].
*   **데이터 흐름 (The Flow):**
    1.  사용자 입력 데이터 $\rightarrow$ **[API Gateway]** 진입점 애니메이션 시작.
    2.  `Authority Meter`: 초기에는 붉은색 계열로 낮은 값을 표시하며, 분석이 진행될수록 수치가 변동하는 모습을 시각적으로 보여줍니다.
    3.  **리스크 분해 (The Lego Blocks):** 선택된 리스크 카테고리(예: 개인정보보호법)가 중심으로 배치되고, 이 법규의 **'핵심 조항 A' $\rightarrow$ '위반 유형 B (실패 메커니즘)'**이 마치 자석처럼 끌어당겨지며 연결됩니다 [근거: Self-RAG].
    4.  **재무적 영향 ($L_{reg}$):** 이 과정에서 시스템은 자동으로 **'재무적 영향 C(벌금액 범위 $L_{reg}$)'**를 DB 스키마 구조와 함께 보여주는 별도의 사이드바 모듈을 팝업합니다 (레고 블록 연결의 최종 결과물).
*   **코다리 데이터 바인딩:** 이 단계에서 API Gateway는 요청 데이터를 처리하며, 만약 **Warning 상태($L_{reg}$ 발견)**가 발생하면, 경고 메시지(예: "⚠️ $\text{GDPR-V5B}$ 규정 위반 가능성 감지")가 팝업과 함께 노이즈 효과를 잠시 강화합니다.

#### 🟢 Phase 3: 통제권 확보 및 권위 봉인 (4~6초)
*(분석 완료 $\rightarrow$ 클라이맥스)*
*   **비주얼 전환:** 화면을 뒤덮었던 불안한 노이즈 패턴(Glitch Effect)이 **갑자기, 그리고 완전히 사라집니다.** 청명하고 깨끗한 블루/그레이 톤으로 급격히 전환됩니다 [근거: Self-RAG].
*   **클라이맥스 애니메이션 (Authority Seal):** 화면 중앙에 커다란 '인장(Seal)' 모양의 모듈이 나타나며, 코다리님의 로직에 따라 **최종 Status 값 (Success/Warning)**을 결정합니다. 이 인장이 사용자 입력 리스크를 덮으며 **황금색 하이라이트**가 폭발적으로 퍼져나갑니다 [근거: Self-RAG].
*   **결과 제시:** 봉인이 완료된 후, 화면에 최종 메시지가 명료하게 나타납니다.
    > ✨ "불확실성 제거 권한 확보 완료: $A_{LP}$ 기준 충족."
*   **CTA 버튼 (The Seal):** '구매하기'가 아닌, **"\[Utility Solver\] 권위 봉인 및 활성화하기 (Activate Authority Seal)"**와 같이 물리적 행위를 상징하는 디자인의 버튼이 화면 하단에 위치합니다 [근거: Self-RAG].

### III. 자가검증 요약
*   **디자인 톤앤매너:** 아날로그 감성(따뜻함)과 첨단 HUD 콘솔 스타일(전문성)을 결합하여 '신뢰와 권위'를 동시에 전달합니다 [근거: AI 1인 기업 고도화 마스터 명세서, 회사 정체성].
*   **기술적 통합:** 코다리님의 API 로직 흐름 (Error $\rightarrow$ Warning $\rightarrow$ Success)을 시각적인 스토리텔링의 주요 변곡점(Phase 2 경고창, Phase 3 인장)으로 활용했습니다 [근거: Self-RAG].
