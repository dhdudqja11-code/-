# 🎬 Reels 비주얼 디자인 브리프: [마음을 묻다]
## Title: '혼란'에서 '통제'로의 시각적 여정 (The Path from Chaos to Control)
**포맷:** Instagram/TikTok Reels (9:16 세로 비율)
**총 길이 목표:** 15~25초 내외

### I. ✨ 디자인 핵심 원칙 및 메타포

| 요소 | 설명 | 적용 방법론 | 근거 |
| :--- | :--- | :--- | :--- |
| **① 감정적 대비 (The Contrast)** | 불안함(Pain)과 안도감/통제력(Assurance)의 극명한 시각적 대비를 통해 메시지 충격도를 높인다. | 톤앤매너 전환: 저채도, 노이즈 $\rightarrow$ 고대비, 네온 글로우 | *Self-RAG* (불안정성 → 정돈됨), *회사 정체성* (따뜻함 + 전문성) |
| **② 권위적 흐름 (The Flow)** | 모든 정보는 '무작위'가 아닌 '시스템 분석을 거친 결과물'처럼 보이게 연출한다. | 데이터 그리드, 논리적 연결선(Flow Lines), 시스템 경고 UI 요소 사용. | *Self-RAG* (A_LP 계산 로직 시각화), *지난 의사결정 로그* |
| **③ 이중 톤앤매너 (The Dual Tone)** | 전반적인 배경과 감성적 메시지는 따뜻하게 유지하되, '위험'을 지적하는 순간에는 차가운 디지털 전문성을 투입한다. | 아날로그 필터(웜 앰버) $\rightarrow$ 사이버/디지털 UI 레이어(네이비/그리드) | *회사 정체성*, *Self-RAG* (따뜻함+전문성의 조화) |

#### 2. 타이포그래피 및 애니메이션 (Typography & Motion)
*   **폰트 세트:** 전문성과 가독성이 높은 산세리프 계열을 기본으로 하되, 감성적 문구는 약간의 세리프(Serif)를 활용하여 대비시킨다. (예: 제목/강조 = 고딕체 / 위로 메시지 = 클래식한 세리프)
*   **폰트 애니메이션:** 글자가 '뿅' 나타나는 것보다, **데이터가 계산되거나 전송되는 듯한 효과**로 등장해야 전문성이 유지된다. (좌우에서 핀치/슬라이드 인, 타이핑 효과).
*   **글리치(Glitch) 효과 활용:** 단순한 시각 효과가 아닌, **'정보의 오류 또는 불안정성'**을 상징하는 메타포로 사용한다. 글자가 떨리는 것이 아니라, 마치 데이터 전송 중 간섭이 생기듯 *짧게 끊어졌다 이어지는* 느낌으로 적용해야 권위성이 유지된다.
