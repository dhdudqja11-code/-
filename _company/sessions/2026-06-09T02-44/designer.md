# 🛡️ Authority Score Card: 최종 UI/UX 및 시스템 가이드라인 v1.0

## 🎨 톤앤매너 핵심 원칙 (The Dualism)
*   **배경 (Default):** 어둡고 미세하게 노이즈가 깔린 다크 모드 그레이 (#1A1D24).
*   **평상시/안정:** 청명한 네온 블루 계열 (#00BFFF - 신뢰, 기술적 명확성)을 주조색으로 사용.
*   **위험(WARNING):** 시스템 경고의 불안정함을 극대화하는 깜빡이는 시안-레드(#FF4D4D)와 글리치 효과를 결합.
*   **권위(AUTHORITY):** 모든 혼란이 사라지고 '진실'이 밝혀지는 순간에만 사용되는 따뜻한 골드 하이라이트 (#FFD700).

## 🚨 State Transition: WARNING (경고) 영역 디자인 상세

WARNING 상태는 사용자가 **규제적 공백(Regulatory Gap)**을 인지하는 최절정의 불안감 구간입니다. 이 단계에서는 '정보 과부하'와 '시스템적 실패'를 시각화하여, 우리 시스템 도입 없이는 안 된다는 강한 필요성을 심어줘야 합니다.

**1. 시각 효과 (Glitch & Neon Overload):**
*   **배경 노이즈:** 일반적인 미세 노이즈에 더해, **좌우로 빠르게 스크롤 되는 컬러 분리(Chromatic Aberration) 글리치 필터**를 적용합니다. 이는 데이터가 불안정하고 '찢어지는' 느낌을 줍니다.
*   **텍스트 깜빡임:** 핵심 리스크 조항($L_{reg}$)이나 계산 공식 $A_{LP}$ 주변의 폰트 색상을 네온 블루와 레드 경고색이 **불규칙적으로 교차하며 빠르게 점멸(Flicker)**하게 만듭니다.
*   **경고 메시지 레이아웃:** 화면 중앙에 `[SYSTEM WARNING: CRITICAL NON-COMPLIANCE GAP DETECTED]` 라는 문구를 크고 거칠게 배치하고, 글자 주변에 네온 레드 테두리를 적용합니다.

**2. 인터랙션 상세 (The Failure Flow):**
*   사용자가 '분석 시작' 버튼을 누른 후, 시스템이 데이터를 처리하는 과정 중 **필수 정보(예: 파기 감사 기록)**가 누락될 때, 화면에 데이터 필드 박스가 나타나며 해당 부분이 네온 레드와 글리치 효과로 깜빡입니다.
*   **피드백:** "Missing Data Point: Right-to-Erasure Audit Trail (GDPR Article 17)" 라는 문구와 함께, 누락된 정보의 **'추정 손실액($\text{Estimated Loss}$)'이 계산되어 빨간색으로 급증**하는 애니메이션을 보여줍니다.

## ✨ State Transition: AUTHORITY (권위 확보) 인포그래픽 템플릿 2종

WARNING 상태를 지나 '진단 및 해결책'에 도달하면, 화면 전체가 일순간 **깨끗한 청명함과 골드 하이라이트**로 정화되어야 합니다. 아래 두 가지는 단순히 정보를 보여주는 것이 아니라, *통제권을 확보했다*는 물리적 증명을 제공해야 합니다.

### 🥇 Template 1: Provenance Chain Map (데이터 출처 추적 지도)
*   **목표:** 데이터가 어떻게 불안정하게 유출될 수 있었는지(위협), 그리고 우리 시스템이 그 모든 경로를 통제하여 안전지대까지 이끌어왔는지를 **흐름도**로 증명합니다.
*   **레이아웃 구조:** 중앙에 큰 흐름도를 배치하고, 시간의 흐름 또는 데이터 이동 방향을 따라 선을 긋습니다. (왼쪽 $\to$ 오른쪽).

| 섹션 | 시각 요소 및 설명 | 색상/효과 적용 원칙 | 근거 지식 |
| :--- | :--- | :--- | :--- |
| **[Start: The Threat]** | 데이터 발생원(DB, CRM 등)을 여러 개의 분산된 '섬'처럼 배치합니다. 각 섬 주변에는 노이즈/글리치 효과를 미세하게 넣습니다. | 네온 블루/그레이 (불안정함) | Self-RAG, 리서처 자료 |
| **[The Gap: Failure Point]** | 데이터가 한 경로(예: 마케팅 서버)에서 빠져나가는 지점을 빨간색 점선과 함께 표시합니다. 이 경로는 '규제적 공백'을 상징하며 명확히 끊어져 있습니다. | 깜빡이는 레드 (위험/공백) | Self-RAG, WARNING State |
| **[The Solution: Authority Protocol]** | 우리 시스템이 개입하는 지점을 가장 밝은 **골드 하이라이트**로 표시합니다. 이 지점에서 데이터는 여러 갈래의 복잡한 경로 대신, 하나의 명확하고 안정된 '권위 통제 라인'으로 수렴됩니다. | 골드 (진실/통제) | Self-RAG, 톤앤매너 |
| **[End: Provenance Seal]** | 최종적으로 데이터가 저장되는 지점(Secure Vault)에 크고 입체적인 'Authority Sealed' 인장 이미지를 배치합니다. 이 인장은 빛을 발하며 신뢰를 전달해야 합니다. | 네온 블루/골드 (안도감) | Self-RAG, CTA 디자인 |

### 🥈 Template 2: Compliance Guard Matrix (규정 보호 매트릭스)
*   **목표:** '어떤 종류의 위협'으로부터 고객을 얼마나 확실하게 지켜줄 수 있는지 **범위와 깊이**를 표로 제시하여 상품 가치를 명료화합니다.
*   **레이아웃 구조:** 3개의 열(Columns)과 N개의 행(Rows)으로 구성된 매트릭스 형태입니다.

| 섹션 | 시각 요소 및 설명 | 색상/효과 적용 원칙 | 근거 지식 |
| :--- | :--- | :--- | :--- |
| **[행 (Row)]** | '위협 리스크 카테고리' (예: GDPR, CCPA, 내부 통제 미흡)를 나열합니다. | 텍스트 기반 (명확한 분류) | 리서처 자료 |
| **[열 1 (Column 1)]** | **"발생 가능 위험(Risk)"**: 위협의 종류와 예상되는 손실 규모($L_{reg}$)를 제시합니다. | 네온 레드/회색 (위험 경고) | Self-RAG, $A_{LP}$ 계산 |
| **[열 2 (Column 2)]** | **"미보호 상태(Unprotected)"**: 현행 시스템의 취약점을 간략히 설명하며 'Gap'을 표시합니다. 이 셀은 네온 글리치 효과가 은은하게 깔려 불안감을 유발해야 합니다. | 어두운 회색 + 미세한 글리치 (불확실성) | Self-RAG, 톤앤매너 |
| **[열 3 (Column 3)]** | **"보호된 권위(Authority Guard)"**: 우리 시스템이 제공하는 구체적인 보호 기능(Solution Feature)을 명시합니다. 여기에 'Protection Level' (예: $\text{Level } \mathbf{3}$)을 표기하고, 해당 셀 배경에 황금색의 미세한 방패/인장 패턴을 입힙니다. | 골드 하이라이트 + 네온 블루 테두리 (확정적 안전) | Self-RAG, 현빈 자료 |
